# 텍스트 스타일 가이드 (사람이 읽기 좋은 여행 계획)

모든 설명 문장(블록 notes, daily_tips, safety_note, flights, general_tips, booking note, budget note, alternatives detail, weather, restaurants hours/reservation)에 적용.

## 원칙
1. **한 줄 = 한 정보.** 줄바꿈(`\n`)으로 구분. 한 줄은 40자 이내를 목표.
2. **숫자·고유명사 먼저.** "10:10 출발 · 11:50 도착 · €40" 처럼 핵심 수치를 앞에.
3. **군더더기 삭제.** "~하는 것이 좋습니다", "~할 수 있습니다", "참고로", "특히", "따라서", "~이므로" 같은 연결·완곡 표현 제거. 명사형/개조식으로.
4. **문장 끝은 마침표 없이** 명사·동사 원형으로 끝냄 ("예약 필수", "도보 8분", "월요일 휴무").
5. **한 항목 최대 3~4줄.** 꼭 필요하면 5줄. 배경 설명·역사·감상은 삭제하고 행동에 필요한 정보만 남김.
6. **줄 앞 글머리표는 붙이지 않음** (렌더링이 줄 단위로 처리). 단, 선택지를 나열할 때는 `- ` 접두사 허용.
7. **괄호 남용 금지.** 괄호 안 부연은 별도 줄로 빼거나 삭제.
8. **경고/주의는 맨 앞에** "⚠" 없이 "주의:" 로 시작하는 한 줄.
9. **고유명사 표기**: 한글 + 원어 1회만. 반복 시 한글만.
10. 시간은 `HH:MM`, 요금은 `€12` / `12,000원`, 거리는 `0.8km · 도보 10분`.

## 예시
### Before
"긴 비행 후 가볍게 굴·하몽 이베리코 콘·크로케타·베르무트 한 잔 정도로 스탠딩 저녁. 일요일 24:00까지 영업, 예약 없이 스탠드별 주문. 관광지 가격(1인 €20~35)이지만 첫날 도착 동선에 가장 편함. 20~22시는 혼잡하니 한 명이 자리 지키고 한 명이 주문, 가방은 앞으로."
### After
```
굴 · 하몽 콘 · 크로케타 · 베르무트로 가벼운 스탠딩 저녁
일요일 24:00까지 · 예약 없음 · 스탠드별 주문
1인 €20~35 (관광지 가격)
주의: 20~22시 혼잡, 가방은 앞으로
```

### Before (항공)
"4/25(일) 09:55 인천 T2 출발 대한항공 KE913(A350-900/B787, 약 15시간) → 같은 날 18:00 마드리드 바라하스(Madrid-Barajas) 도착(시차 -7시간, 서머타임 기준). 09:55 출발은 울산에서 당일 이동이 사실상 불가하므로 …"
### After
```
4/25(일) 23:55 인천 T1 → 에미레이트 EK323 → 두바이 04:xx
두바이 환승 2h50 → EK141 → 4/26(월) 13:xx 마드리드 T4S
총 소요 약 21시간 · 시차 -7h
```
